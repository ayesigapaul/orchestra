# Requests for Comment

An RFC is a proposal open for discussion. It becomes an
[ADR](../adr/) once a decision is reached, or is closed if it is not adopted.

Write an RFC when the right answer is not yet clear and the question is worth structured debate.
Write an ADR when the decision has been made.

Naming: `rfc-NNNN-short-title.md`. Numbers are never reused.
